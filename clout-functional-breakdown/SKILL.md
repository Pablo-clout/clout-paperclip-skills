# clout-functional-breakdown

Transform an approved functional specification into a structured feature breakdown and well-defined English user stories ready for technical architecture and implementation.

## When To Use

- Use this skill after spec.md is confirmed by the user to slice the product into independent functional modules and generate user stories.

## Workflow

1. Inspect the approved spec.md and verify that all functional ambiguities are resolved; invoke clout-grill-me first if critical gaps exist.
2. Slice the specification into cohesive functional domains and prioritized epics, defining clear boundaries and dependencies between features.
3. Write detailed user stories, technical documentation, and subtasks in strict English containing role, goal, business value, and testable acceptance criteria.
4. Present the feature breakdown and user stories for handoff to the Enterprise Tech Lead.
