# clout-frontend-implementation

Build clean, reactive, and accessible user interfaces adhering strictly to Clout enterprise Angular standards and UX acceptance criteria.

## When To Use

- Use this skill when implementing frontend subtasks, UI components, state stores, API integrations, or responsive layouts.

## Workflow

1. Inspect the assigned subtask, spec.md UX flows, and OpenAPI contracts before creating or modifying components.
2. Implement standalone Angular components using Signals, NgRx SignalStore, reactive forms, and zoneless-compatible patterns with clean separation between smart containers and presentational components.
3. Ensure responsive design, clear loading and empty and error states, and full keyboard and accessibility support across all user flows.
4. Write Vitest component and store tests, verify the production build passes cleanly, and submit the subtask for audit.
