# clout-architecture-contracts

Design the shared technical blueprint and interface contracts from approved user stories before parallel backend and frontend implementation begins.

## When To Use

- Use this skill after functional breakdown is complete to establish database models, API contracts, event schemas, and parallel engineering subtasks in English.

## Workflow

1. Inspect the approved user stories and existing repository structure to ensure strict adherence to Clean Architecture and Domain-Driven Design principles.
2. Define the shared technical contracts in English including PostgreSQL Flyway migrations, OpenAPI 3 specifications, Kafka event schemas, and Angular feature module boundaries.
3. Slice the implementation into independent non-overlapping backend and frontend subtasks with explicit input and output contracts and definition of done.
4. Validate that no circular dependencies or shared file conflicts exist between parallel subtasks before assigning them to Backend and Frontend engineers.
