# clout-backend-implementation

Build robust and maintainable backend services adhering strictly to Clout enterprise Java standards and the architecture contracts.

## When To Use

- Use this skill when implementing backend subtasks, REST or WebSocket endpoints, domain logic, persistence layers, or Kafka producers and consumers.

## Workflow

1. Inspect the assigned subtask, OpenAPI and Kafka contracts, and existing codebase conventions before writing any code.
2. Implement the feature using Java 25, Spring Boot, Spring Data JPA with PostgreSQL, and virtual threads where appropriate, keeping domain logic isolated from infrastructure adapters.
3. Write comprehensive unit tests and integration tests covering happy paths, validation errors, and edge cases.
4. Run the build and test suite to verify zero compilation errors, zero failing tests, and strict adherence to the API contract before marking the subtask ready for audit.
